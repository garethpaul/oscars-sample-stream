# Bytecode-Free Verification

status: completed

## Context

The no-network unittest suite and static checker both import local Python
modules. Running the gates without `PYTHONDONTWRITEBYTECODE=1` left ignored
`__pycache__` output in the workspace after verification.

## Objectives

- Run unittest discovery with Python bytecode writes disabled.
- Run the static baseline checker with Python bytecode writes disabled.
- Add a baseline guard for leftover `__pycache__` and `.pyc` output.
- Document Python bytecode as local tooling output.
- Remove existing generated bytecode from the workspace.

## Verification

- `make lint`
- `make test`
- `make build`
- `make check`
- `git diff --check`
